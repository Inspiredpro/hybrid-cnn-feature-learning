
# Hybrid CNN Feature Learning

## Overview

This project investigates whether deep feature representations learned by convolutional neural networks can improve image classification performance when combined with tree-based ensemble methods such as LightGBM.

## Objectives

- Train a CNN
- Extract learned feature embeddings
- Train LightGBM on extracted features
- Compare against end-to-end CNN classification
- Analyze results statistically
